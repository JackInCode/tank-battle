# 坦克大战 (Tank Battle)

一个使用纯 HTML + Canvas + JavaScript 编写的经典坦克大战游戏，无需任何依赖，单文件即可运行。

## 在线游玩 / 本地运行

直接用浏览器打开 `index.html` 即可开始游戏。

也可以启动一个本地服务器：

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```

然后访问 http://localhost:8000

## 操作方式

| 按键 | 功能 |
|------|------|
| `W A S D` / 方向键 | 移动坦克 |
| `空格` | 射击 |
| `P` | 暂停 / 继续 |
| `R` | 重新开始 |
| `回车` | 开始游戏 / 进入下一关 |

## 游戏规则

- 保护底部的金色基地，基地被摧毁则游戏结束
- 消灭每一关的所有敌方坦克即可过关，关卡难度递增
- 敌方坦克有三种：
  - ⚪ 普通坦克（灰色）
  - 🔵 快速坦克（蓝色，移动更快）
  - 🔴 重型坦克（红色，需要 3 发子弹击毁，炮弹可击穿钢墙）
- 击毁敌人有概率掉落道具：
  - ★ 星星：+500 分
  - ♥ 红心：+1 生命
  - 盾：临时无敌护盾
- 地形：砖墙（可击破）、钢墙（仅重型炮弹可破）、水域（阻挡通行）、草丛（隐蔽）

## 技术说明

- 单文件实现，零依赖，Canvas 2D 渲染
- 网格地图 + AABB 碰撞检测
- 简单的敌方 AI（倾向于向基地推进 + 随机游走）
